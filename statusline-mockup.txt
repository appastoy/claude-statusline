================================================================
폴더 표시 규칙 (우선순위 순)
================================================================
  1. current_dir == 홈(%USERPROFILE% / $HOME)   → "~"                       (파랑)
  2. current_dir 이 project_dir 의 하위          → "<프로젝트명>\<상대경로>"   (프로젝트명=파랑, 상대경로=청록)
  3. 그 외 (프로젝트 루트 / project_dir 없음 / 밖) → 현재 폴더 leaf 이름         (파랑)


================================================================
색 기준  (문맥·한도 모두 "높을수록 경고" — 같은 임계값 재사용)
================================================================
  문맥(ctx) — 사용 %, 높을수록 경고
     0-49 초록 / 50-74 노랑 / 75-89 주황 / 90-100 빨강
  한도(5h/7d) — 사용 %, 높을수록 경고 (웹 사용량 페이지와 동일)
     0-49 초록 / 50-74 노랑 / 75-89 주황 / 90-100 빨강
  리셋 시각은 항상 표시
     5h → HH:mm                예) 14:30
     7d → {n}d(요일) HH:mm      예) 2d(수) 07:00
          내일(요일) HH:mm      예) 내일(목) 12:34   (1일 남음)
          오늘(요일) HH:mm      예) 오늘(금) 23:42   (오늘 리셋)
